# IELTS Radar｜我的 AI 雅思侦察日志 📡

> **“每天精读 10 篇真实社媒生态 · 沉淀高分备考认知”**
> 采用 **Apple × Notion × Linear** 极简白底设计风格，专注内容阅读体验，具备本地全量持久化存储与双 Agent 归并能力。

---

## 🌟 1. 项目背景与三大核心研究目标 V2.0

系统的根本目的，是通过**每天了解 10 篇雅思相关内容**，逐渐认识这个领域正在发生什么，以及读者正在关注什么、需要什么。**不是单纯收集爆款，也不是立即模仿创作**。

围绕以下三个核心问题组织整个系统的阅读与记录：

1. **① 发现：最近有什么值得关注？**
   - 最近 30 天，雅思领域出现了哪些受到关注的内容？（标题、平台、发布日期、互动数据、原文链接）
2. **② 理解：这些内容究竟在讲什么？**
   - 作者讨论了什么问题？提供了什么观点、信息或方法？（客观内容简介 `summary`）
3. **③ 价值：对读者有什么帮助？**
   - 解决了读者什么问题？满足了什么需求？读者看完能获得什么？（简明读者价值 `reader_value`，根据实际提供的信息判断，无足够信息则留空，绝不编造）

你部署的两个专属侦察 Agent：
- **🔴 WorkBuddy**：每天在小红书、抖音筛选 5 篇内容。
- **🔵 Muse**：每天在 YouTube、Reddit、X 筛选 5 篇内容。

## 📱 3. 核心功能与使用指南

### A. 每日记录（首页时间线）
- **首页三问核心导向条**：以极简、不占空间的方式置顶提示核心研究目标 V2.0。
- **纵向时间线**：按日期倒序排列，最新日期置顶展示。
- **双 Agent 专栏清晰归并**：
  - 🔴 **WorkBuddy 专栏**（小红书 / 抖音）
  - 🔵 **Muse 专栏**（YouTube / Reddit / X）
- **每篇卡片围绕三问组织**：
  - **① 发现**：平台微晶标签、发布日期、互动数据（赞/藏/评/Upvotes）、标题与原文链接
  - **② 理解**：客观内容概要（`summary`）
  - **③ 价值**：对读者有什么帮助（`reader_value`，兼容旧数据，无足够信息可留空）
  - 痛点与核心简介（大字距舒适排版）
  - 🔗 原文链接（一键新标签打开）
  - 阅读状态切换（`○ 标记已读` ➔ `✓ 已读`，已读自动降低饱和度，进度条实时更新）
  - ✏️ 快捷修改与 🗑️ 删除条目
- **搜索与筛选**：支持按关键词搜索、按平台筛选、按已读/未读状态筛选；支持一键展开/折叠。

### B. Agent 结果导入（核心交互）
点击顶部导航右侧高亮的 **「📥 导入日报」**：
1. **输入方式**：
   - 直接粘贴 Agent 输出的文本内容；
   - 或点击 **「📂 上传文件」** 选择 `.md`、`.txt`、`.json`；
   - 或点击 **「⚡ 快速测试样例」** 一键载入 WorkBuddy (5篇) 或 Muse (5篇) 进行体验。
2. **结构化识别与容错**：
   - 自动提取标题、平台、发布日期、互动数据、简介与链接；
   - 无法准确识别的字段自动标记为 **「待确认」**，坚决不瞎编造；
3. **保存前预览与实时修正**：
   - 列表展示解析出的条目，可在输入框内直接修改任何字段；
   - **智能去重拦截**：检测当天已有记录的链接，若重复则黄色告警，允许选择「跳过」或「覆盖更新」；
   - 自动关联当前生效的提示词版本。
4. **确认归档**：
   - 点击确认后，两批内容自动合并到目标日期，汇聚为 **10 篇**！
   - 原始报告自动存档在 `data/raw-reports/`，便于日后追溯。

### C. 提示词版本库 (Prompt Registry)
- 分别管理 **WorkBuddy** 与 **Muse** 的提示词版本历史。
- **不可直接覆盖旧版本**：发布新版本时自动递增版本号（如 V1.0 ➔ V1.1 ➔ V1.2），保存创建时间、修改原因与变更日志。
- **并排比较器 (Side-by-side Diff)**：
  - 选择任意两个版本（如 V1.0 与 V1.1），系统即时渲染左右对比视图，红色删除高亮、绿色新增高亮，一目了然看清规则演进！
- **一键复制**：活跃版本支持一键复制完整提示词。

### D. 我的目标与想法 (Goals & Memos)
- 自由记录四大维度：
  1. 🌟 我为什么建立这套系统（定位初衷）
  2. 🎯 目前的核心目标（阶段性里程碑）
  3. 🧭 侦察策略与执行原则（日常阅读守则）
  4. 💡 过程中产生的新想法与观察（灵感与反思沉淀）
- **认知快照**：每次保存均生成带时间戳的历史快照，在侧边栏时间线随时回顾认知演变。

### E. 数据管理与备份安全
- **持久化存储**：数据实时持久化至磁盘文件 `data/radar-store.json`，刷新页面或重启服务绝不丢失。
- **自动安全轮转备份**：每次保存自动在 `data/backups/` 目录下生成带时间戳的副本，自动保留最新 20 份备份。
- **导出功能**：
  - 点击顶部 **「💾 导出数据」➔「导出精美复盘 Markdown」**：一键生成排版工整的 Markdown 复盘笔记（可直接导入 Obsidian / Notion）；
  - 点击 **「导出完整备份 JSON」**：导出全量数据备份。
