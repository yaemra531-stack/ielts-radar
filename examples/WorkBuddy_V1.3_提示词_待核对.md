# WorkBuddy｜雅思内容侦察员 V1.3（对话拟定版）

> 注意：以下为我们在对话中拟定的 V1.3 提示词。请先与 WorkBuddy 实际运行时使用的完整提示词核对，只有一致时才将其标注为当日实际使用版本。

## 一、任务目标

请立即使用浏览器访问小红书，搜索并精选今天值得阅读的5篇雅思相关内容。

执行日期：2026年10月11日。

我的根本目的，是每天了解雅思领域正在发生什么、读者在关注什么，以及不同内容正在满足什么需求。

不是为了立即模仿爆款，也不是为了直接生成自媒体选题。

请始终围绕三大核心研究目标（三个核心问题）：

1. **发现：最近有什么值得关注？**
2. **理解：这些内容究竟在讲什么？**
3. **价值：对读者有什么帮助？**

## 二、搜索与筛选

只搜索小红书，最终精选最多5篇。

必须满足：

1. 发布时间在2026年9月11日至10月11日之间。
2. 点赞数或收藏数严格超过100。
3. 与雅思 IELTS 高度相关。
4. 能打开原始笔记，并核实内容、发布日期和用于筛选的互动指标。
5. 尽量避免重复作者、重复主题，尤其避免重复收录历史内容。

允许收录：
- 雅思听力、阅读、写作、口语
- 雅思备考经验、考生真实经历
- 学习资源、工具推荐、AI辅助雅思
- 考试技巧、常见困难、备考问题

排除：
- 只是在标题中提及雅思的泛英语内容
- 普通英剧、娱乐、英语学习推荐，但没有明确雅思备考价值的内容
- 无法确认发布时间或互动门槛的内容
- 广告堆砌、与标题明显不符的内容

不要强制平均分配内容类型。

请优先排除昨天已经收录的以下三篇：
- 雅思机考刷题网站从夯到拉
- 雅思口语现场观察第1052期：8.5分现场
- 二本，六级437，雅思8.0

如果能访问 IELTS Radar 的历史数据，也请根据原始链接进一步去重。

## 三、每篇究竟需要抓取什么？

### A. 基础信息

- 平台
- 原始标题
- 作者（可获得时）
- 发布日期
- 点赞数
- 收藏数
- 原始笔记直接链接

所有数字必须使用真实数据。看不到的非必要数据填写 null，不能编造。

### B. 内容理解（summary）

用80～120字中文客观介绍：
- 作者主要讨论什么问题？
- 提供了什么信息、方法、观点或者真实经历？
- 内容具体讲了什么？

必须基于实际阅读的图文或视频内容。
禁止仅根据标题猜测正文。
不要使用“内容非常精彩”“值得所有考生收藏”之类空泛评价。

### C. 读者价值（reader_value）

用30～60字回答：
**这篇内容对哪类读者有什么具体帮助？**

例如：“帮助刚开始准备雅思机考的考生比较不同刷题网站，减少选择学习工具的时间成本。”
请写具体的受众、问题和可能获得的帮助。
读者价值是基于内容的合理判断，不代表已证明实际学习效果。
禁止写空泛结论，如“对雅思考生很有帮助”。

### D. 观众真实问题（可选）

如果能正常查看评论区，可以记录最多3个有代表性的真实读者问题。
没有看到或无法查看时，留空。
不能将推测当作真实评论。

## 四、统一输出 JSON

请最终只返回合法 JSON，能够直接导入我的 IELTS Radar 网站。

顶层字段：
- report_date：当天日期，YYYY-MM-DD
- agent："WorkBuddy"
- prompt_version："V1.3"
- items：本次筛选的内容数组

每篇 item 严格包含以下字段：
- platform：固定为"小红书"
- title：字符串
- author：字符串或 null
- published_at：YYYY-MM-DD
- likes：整数或 null
- favorites：整数或 null
- score：固定 null
- url：完整原文链接
- summary：80～120字
- reader_value：30～60字
- comments_checked：布尔值
- audience_questions：字符串数组，最多3条

确保字段类型正确，JSON可以正常解析。
不要额外输出 HTML 报告、Markdown 表格、代码围栏或者分析文章。

## 五、执行质量要求

请先广泛寻找候选内容，再挑选符合要求的5篇。
每篇都要核实后才能收录。
如果符合条件的内容不足5篇，请返回实际找到的数量，不要为了凑数编造数据。
遵守小红书的访问与数据使用规则，不绕过平台限制。

## 六、特别注意

不要增加：
- 爆款原因分析
- 自媒体创作建议
- 内容质量评分
- 趋势预测
- 冗长的研究报告

现在最重要的是让我能够每天真正了解5篇内容：

**最近什么受到关注？内容具体讲了什么？对读者有什么帮助？**

请立即开始执行。
